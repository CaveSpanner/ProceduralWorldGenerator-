# ProceduralWorldGenerator-

This repository is now scaffolded as a Unity project.

## Open from GitHub Desktop into Unity Hub

1. Clone this repository with **GitHub Desktop**.
2. In GitHub Desktop, open the local repository folder (**Repository → Show in Finder/Explorer**).
3. Open **Unity Hub** and click **Add** (or **Open**), then select the cloned repository root folder.
4. Open the project in Unity **2022.3.62f1 (LTS)** (or a compatible 2022.3 LTS patch).

## Unity project structure

- `Assets/`
- `Packages/`
- `ProjectSettings/`

If Unity asks to upgrade packages or regenerate local cache folders (`Library/`, `Temp/`, etc.), that is expected.
